# Complete Story Recommendations

This repository contains the complete story catalogue in two formats:

- [Complete Markdown catalogue](./complete_story_recommendations.md)
- [Standalone HTML catalogue](./complete_story_recommendations.html)

The Markdown catalogue contains 414 categorized entries with descriptions, main links, trailer/preview links, years, formats, episode information, runtimes, and metadata sources where publicly available.

The HTML file is a standalone searchable catalogue suitable for GitHub Pages or local browser use.

Links are third-party discovery links. Availability, regional access, pricing, episode counts, runtimes, and platform terms may change. Users must follow the rules of the original platform and respect the rights of authors, publishers, producers, and copyright owners.
